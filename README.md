# Website Profil — Daiva Rafa Janitra

Website profil pribadi sederhana dengan desain responsif dan gradasi biru muda.

## Cara memasang di GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah file `index.html` ke bagian utama (root) repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
6. Tunggu proses publikasi. GitHub akan menampilkan alamat website di halaman Pages.

## Galeri
Foto bermain gitar ditampilkan dari `assets/galeri-gitar.jpg`. Untuk menambah foto, unggah gambar lain ke folder `assets/` lalu tambahkan elemen `<img>` pada bagian `#galeri` di `index.html`.

## Privasi
Jangan publikasikan alamat rumah lengkap atau nomor HP pribadi di website publik, terutama jika website dapat diakses siapa saja. Template ini sengaja tidak menampilkan nomor HP, alamat rumah, dan email pribadi. Jika perlu kontak publik, gunakan email khusus yang memang disiapkan untuk keperluan tersebut.
